### Tech Stack [Made with Typescript]
- Vite (for server)
- React (for frontend framework)
- Tailwind (for css framework)
- Zustand (for state management)
- Lucide (for icons)
- Fontsource (for fonts)
- React-Color (for color-picker)

<hr/>

## How to run

### Clone the code 
```js 
git clone https://github.com/iam4tart/zocket-frontend.git
```

### Install Dependencies

```js
npm install
```

### Start the webapp in developer mode
```js
npm run dev
```
